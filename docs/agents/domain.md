# Domain docs

This repository uses the single-context layout.

Before exploring or changing a domain, read:

- `CONTEXT.md` at the repository root for canonical terminology.
- Relevant decisions under `docs/adr/`.

Use the glossary vocabulary from `CONTEXT.md` in ticket titles, plans, tests,
and user-facing explanations. If a change conflicts with an ADR, call out the
conflict before implementation rather than silently overriding it.
