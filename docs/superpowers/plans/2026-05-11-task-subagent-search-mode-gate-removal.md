# Task Subagent Search-Mode Gate Removal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the remaining lifecycle-critical `search-mode` gates so native OpenCode `task` tool activity reloads, anchors, arms, and clears consistently for ordinary user messages.

**Architecture:** Keep the current background-task owner boundaries. `BackgroundTaskTimelineAssemblyService` remains the persisted message/runtime segment assembler, `BackgroundTaskTimelineService` remains the runtime facade and inline renderability owner, and `BackgroundTaskLiveSignalCoordinator` remains the live/grace/stale signal owner. OMO `search-mode` stays as metadata and fallback context, not as the functional gate for native task lifecycle behavior.

**Tech Stack:** TypeScript, Jest, Obsidian plugin runtime types, existing OpenCodian background-task services, `npm run graphify:update:src`, module-doc guards, full `npm run verify`.
