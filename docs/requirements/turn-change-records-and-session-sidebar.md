# 单轮文件变更记录与会话变更侧栏

## 目标

让 OpenCodian 的文件变更信息同时服务两类不同的问题：会话历史中的“这一轮做了什么”，以及当前 OpenCode 会话中的“到现在改了什么”。两者必须真实、可发现、可追溯，且不能被误解为仓库级 Git 状态。

## 领域模型

- **单轮文件变更记录（Turn Change Record）**：一条完成 agent 回合的不可变、本地持久化证据。它列出该回合涉及的文件、added/modified/deleted 状态和可用的增删行数。
- **会话变更侧栏（Session Change Sidebar）**：当前 OpenCode session 的可变汇总投影。它不代表整个仓库的 Git 工作区，也不能取代单轮历史记录。
- **后台任务完成记录**：后台子任务在主回复完成后继续产生的文件变更，必须另记一条记录，锚定发起该任务的回合，不得改写旧记录。

## 已确认的产品契约

### 单轮文件变更记录

- 每个完成 agent 回合最多生成一张汇总卡；同回合重复路径去重。
- 卡片属于会话历史，跨标签切换、会话加载和 Obsidian 重启后仍可见。
- 卡片是不可变快照：后续修改或回滚必须由后续回合的新记录表达。
- 后台任务的后续文件修改以单独完成记录表达，不更新主回合的卡片。
- 卡片继续使用当前简洁的 notice 样式，不在本期重做视觉设计。
- 设置 > 会话新增全局、默认开启的“显示本轮文件变更卡片”。关闭只隐藏现有与后续卡片，不停止收集或持久化；重新开启时恢复同一会话的完整历史记录。

### 会话变更侧栏

- 侧栏保留为当前 OpenCode session 的变更概览；其现有“UI”设置开关继续独立存在。
- 设置开启时，聊天右缘保持一个 48px × 40px 的窄边缘感知区：鼠标接近时淡入可点击的 shadcn 风格 outline icon button，键盘聚焦时也会显示；指针离开且失焦后入口隐藏。有变更显示小型文件数 badge，已就绪但无变更显示准确空状态，OpenCode/当前会话未就绪显示准确等待状态。展开后的面板不因移出或失焦自动收起；它不能退化成无标签的竖条或抢占整条右侧滚动区。
- 入口点击展开或收起；面板内明确关闭按钮必须立即收起并阻止冒泡，Escape 也能收起并恢复入口焦点；失焦或移出不自动收起。
- 新变更出现时不自动展开或抢焦点；收起态更新摘要并提供克制的状态反馈。
- `AgentCapability.Context` 只控制是否能读取当前会话 diff 与不可用文案，不控制入口可发现性；OpenCode 之外的对话可以显示入口，但必须明确说明面板只展示当前 OpenCode 会话变更，不能伪装成 Git 工作区状态。
- 展开面板显示“本会话变更”摘要与可折叠文件列表。点击文件路径在 Obsidian 中打开文件。
- 本期不提供伪造的逐行 diff 预览；只有在将来具备可靠 patch 数据源后才能新增该能力。

## 参考设计的边界

- 借鉴 Codex 的“变更计数与增删统计优先”的摘要层级。
- 借鉴 ZCode 的“先总览、后分层展开”的信息组织。
- 不复制参考产品的视觉皮肤、Git 术语或仓库级语义；OpenCodian 保持 Obsidian 原生主题、紧凑工作台密度和 session.diff 语义。

## 验收场景

1. 一个完成回合编辑多个文件后，历史中出现一张对应的不可变卡片，路径可打开，状态和行数正确。
2. 重载插件、重启 Obsidian、切换到别的标签再返回后，同一张历史卡片仍在原回合之后。
3. 关闭“显示本轮文件变更卡片”后，卡片立即隐藏且后续回合不显示；重新开启后，同一会话此前与之后收集的卡片均恢复。
4. 后台任务在主回复后改文件时，产生单独的完成记录，而主回复的记录不发生变化。
5. 当前 OpenCode session 有变更时，右侧入口展示文件数与 `+/-` 汇总；已就绪空状态和未就绪状态同样可点击并展示准确说明，点击能可靠展开，关闭按钮与 Escape 能立即收起。
6. 侧栏切换会话后只显示该会话的 session.diff 数据；文件点击在 Obsidian 中打开真实文件。
7. 无变更、未就绪、禁用侧栏、窄聊天窗、键盘聚焦和降低动态效果偏好均不产生遮挡、不可达或自动抢焦点问题；入口和面板不依赖悬浮或鼠标移出行为。

## 非目标

- 不将 session.diff 伪装或扩展为 Git 工作区状态。
- 不增加逐行 diff 预览、提交/推送、分支比较或仓库来源管理。
- 不改变 OpenCode canonical message 的服务端契约。
