2026-11-11（展开与仓库打磨）：信息分组与命令目录采用统一的单框 disclosure——折叠时透明，展开后标题与内容共享 1px 主题边框、10px 圆角和轻微 tonal surface，内容区不再统一缩进 16px；内部数据行、来源小标题、额度窗口、空状态和终端输出各自承担层级，禁止再嵌套卡片。搜索图标以 32px 输入框为定位上下文，左内边距 10px、垂直居中。仓库头部为分支/操作 + 独立路径的两行网格，文件行显示文件名与父目录，路径及 Git 状态显式清除默认 code 背景；提交输入为 64px 起始高度，提交操作右对齐。所有颜色、字体和焦点继续继承 Obsidian token。

2026-11-11：一级以单行控制、可展开列表和独立视图入口区分层级：Plan 与折叠标题共用 34px 行高，折叠列表使用向下箭头，工具分组为 11.5px muted 非交互标签，展开内容使用独立内边距。内联命令目录保持稳定 DOM、限制列表高度并独立滚动；文件详情嵌入时隐藏重复标题与折叠触发器，保留权威摘要。三种工具统一状态／工作区／低频操作布局；仓库提交说明成独立 form、工作树管理折叠；浏览器地址 form 与预览状态分区，空／读取／失败反馈覆盖在同一预览区域，避免状态层与 webview 高度相加而把操作推到屏外。分组计数独立对齐，placeholder 使用主题 muted 色且保持不透明。已完成待办以 muted 色加删除线表示，避免 faint 色在深色主题下低于文字对比度要求。主区域工具复用相同列表对齐和主题 token，窄栏次级动作保留图标及无障碍名称。终端原生键盘区域由 DOM 标记与控制器配合，CSS 不改变 PTY 生命周期。

2026-11-10：子会话续接输入沿用共享面板，使用72px起始高度、主题边界与紧凑分段投递按钮。输入和操作行允许压缩／换行，投递说明单独占行，发送按钮保持内容宽度；仅在子转录与输入之间用一条轻分界，不嵌套新卡片或新增 DSH 专属外壳。焦点提示和选中态继承 Obsidian token；选中投递选项保持 `--text-normal` 配合悬停底色，避免宿主浅色主题把 accent 设为白色时降低文字对比度。样式 inspector 对此 CSS 未解析 owner，文档中的 style 是历史职责标签，不作为新 manifest owner 事实。

会话信息与功能卡片主题样式。320px 默认内容高度浮层、34px 摘要胶囊、32px 列表行、16px shell 圆角与 26px ghost controls；颜色和字体继承宿主。会话信息与具体卡片均显示独立标题行和右侧控件，具体卡片另有返回按钮；不再提供四页签或嵌套工具选择器样式，空计划/任务不占版面。展开与停靠、主区域工具、内联会话文件列表、composer Goal 行及 reduced-motion 样式同处维护。

信息分组与工具入口不使用横向分隔线，以行间距和组间留白区分；底部任务/工具入口使用单列整行布局，图标、标签和末端箭头沿相同轴线对齐。标题控件占独立一行，避免与套餐额度等摘要挤在一起。

卡片标题区域允许压缩并保持返回按钮对齐；隐藏返回按钮不占布局，键盘返回后焦点移至目标卡片内可操作元素或 region，避免停留在已隐藏控件。

## 会话信息面板（2026-10-31）

新增真实用量 progress、紧凑统计行、截断但可查看完整值的折叠摘要、原生子会话文本/工具布局和键盘焦点样式，全部复用 Obsidian 颜色及排版 token。

composer Goal 行不带底部分隔线。已完成目标的关闭按钮保持独立点击区域，隐藏状态不占布局；目标按钮的完成/受阻语义色继承宿主 token，SVG 使用 OpenChamber 原始箭靶路径。目标详情视图沿用同一面板的边界、滚动与键盘行为。

目标入口使用纯 SVG 按钮：默认、悬停、按下和焦点均无边框、底色或阴影。颜色只由真实目标/预备状态驱动：信息蓝、暂停灰、受阻/限制警告色、完成成功色；SVG 继承 currentColor，悬停不覆盖语义颜色。键盘焦点只轻微放大 SVG，保持颜色及中心坐标。26px 点击区域与同一状态行的上下文圆环一致，SVG 外层显式 flex 居中与零行高，避免宿主通用按钮样式和基线排版造成偏移。

停靠按钮遵守 `[hidden]`（覆盖按钮通用 display），有效停靠通过 `aria-pressed="true"` 使用主题选中样式。

停靠时聊天列已为侧面板预留独立宽度，侧面板底边使用 `--workbench-dock-bottom` 与可见输入框外框下边缘对齐，不延伸到下方状态栏；测量缺失时回退到 `--workbench-inset`。浮动和展开状态仍使用 `--workbench-bottom` 避让输入区。
