# settings-opencode2

源码：`src/style/components/settings-opencode2.css`。

2026-11-12 组件修复：普通连接 Setting（包括分段选择、自定义程序路径、远程地址/密码）和权限 choice-setting 都显式复用页面字段两列栅格：自适应文字列 + 220–300px 控件列，≤760px 单列。控制列是无换行纵向栈，choice gap 6px、hint margin 0，排除通用 flex-end/换行导致的内容宽度漂移和间隙放大。辅助元数据保留全部事实，以11px配对标签呈现。页头允许换行、简介12px/1.6、标题区后12px和scope后24px分层；刷新按钮显式28px高、透明次要样式。连接状态任务只在本页用两列放置文案与右侧操作，≤760px操作左对齐排在文案下方，保留12px实际间隔。无 TypeScript、配置行为或其他后端样式变更。

OpenCode 2 设置工作区的局部样式，按已批准的 revision 2 设计（`.tmp/opencode-settings-design/` 原型与 `.impeccable/opencode-settings-direction.md`）实现 DSH 家族视觉：单一集合外框、框内平铺字段、原生 disclosure，全部继承宿主 Obsidian 主题变量，根节点保持透明，无框架运行时依赖。

- 表单规则以 `.opencodian-settings .opencodian-opencode2-settings.opencodian-settings-section` 限定，不影响其他后端；显式 section 类使规则优先于共享布局和后导入的 backend workspace 行样式，字段保持透明、无边框的平铺布局。内容居中且最大宽度 1030px，`[hidden]` 保持隐藏；上方任务标签通过 OpenCode 2 的 `data-backend-workspace` 限定并自然换行，栏间距显式恢复共享分类导航的 12px（backend workspace 样式表对非 DSH 后端的 6px gap 在此被覆盖）。
- 间距集中在根节点语义 token：集合头部 16/18、列表栏 12、编辑器 20/22/18、字段行 16（页面）/13（编辑器）、子分区 18/16、记录页脚 22/14、页面页脚 20/12（draft-state 感知，见页脚条目）、描述间隔 6；正文使用块级流 + 语义 margin（相邻 margin 正常塌缩），不用 flex-gap 包裹层，避免双重边距。页面与分组说明不设固定 65ch 字符上限，按可用阅读宽度换行。
- 页面标题 h3 为 25px/500 衬线（Songti SC/STSong/Georgia）；普通字段名 15px/600、描述 12px；编辑器/disclosure/model 子编辑器内子字段名 13px/600。
- 集合（`.opencodian-opencode2-collection`，与 `.opencodian-opencode2-group` 同元素）：外框 1px/8px，头部 h4+count 左、新增按钮 `margin-inline-start: auto` 推右；`.opencodian-opencode2-split` 仅一条顶部分隔线（218px 索引 + 编辑器），不产生第二层外框；选中记录行用 `aria-pressed` 背景态。
- 编辑器字段控制列为纵向栈：input/select/textarea 顺序 0（宽 100%、min-height 37），错误 `order: 90`，reset `order: 99` 且 `align-self: flex-end`；空反馈（field-error、editor-footer、save-status、editor-id/status 等）`:empty` 折叠。fieldset/`.native-fields` 复位以支持 select+input 组合栈。增强下拉容器使用 `flex: none`，避免共享的横向 240px flex basis 在纵向控件里变成高度；隐藏原生 select 保持 1px，不参与可见布局。增强下拉的可见 trigger 在本 section 内压平为 DSH 家族的宿主主题表单控件：37px 最小高、7px 圆角、12px 字号、纯色 `--background-modifier-form-field` 表面，rest/hover/open 均无渐变与投影（hover 仅边框过渡到 `--background-modifier-border-hover`），键盘焦点保留 2px accent outline。
- `.opencodian-opencode2-choice-setting` 将连接方式、执行路径来源和默认权限模式的选项压为简短标签按钮：flex 可换行、gap 3、padding 3、8px 圆角、`--oc2-secondary` 底，单元 31px 居中、6px 圆角、radio 收缩为 1px 隐藏（保留键盘焦点）。按钮内不放说明或推荐徽章；当前选项说明由独立 `.opencodian-opencode2-choice-hint` 在整组下方显示（12px/1.7、由父级gap提供6px间距且自身margin为0），空说明不占位。行级作用域/风险/生效信息保留，长标签可换行，不影响其他后端控件。
- 服务商模型子列表（`.opencodian-opencode2-models`/`-model-item`/`-model-editor`/`-model-actions`）为编辑器内的平铺分区：仅顶部 rule，行按钮 `aria-expanded` + CSS chevron（收起朝右、展开朝下，右向路径 `m9 6 6 6-6 6` + 90°），操作行与收起头部之间保留 16px 间距，行内 `.opencodian-opencode2-item-copy` 携带 13px 名称 + 11px 摘要两行；KV 行为 key/value/remove 等宽三列栅格（1fr/1fr/auto，对齐 DSH pair 行），输入与原生按钮同为 34px、按钮 12px 可读标签；规则行 fieldset 保留 `.opencodian-opencode2-rule`，`legend.opencodian-opencode2-rule-legend` 视觉隐藏（语义占位），可见序号在 `.opencodian-opencode2-rule-header > strong`（flex 1，工具栏 `margin-inline-start: auto` 靠右），字段栅格 3 列 + custom 通栏、标签 text-align start，页面或编辑器小于 490px 时改为单列；绑定规则集合 `.opencodian-opencode2-rule-collection` 为单一边界外框（1px/8px、16/18 内边距，≤490 收紧为 14px），`.opencodian-opencode2-rule-collection-header` h6+count+顶部新增按钮，框内规则平铺无嵌套框，restore/reset 仍留在边界外。
- 搜索槽位可能是 input 本身（void 元素恒匹配 `:empty`，因此该槽位不参与 `:empty` 折叠）；无匹配空态用中性 muted 的 `.opencodian-opencode2-empty`，不复用错误红。h5/h6 记录标题可换行（`overflow-wrap: anywhere` + `min-width: 0`）避免长 ID 撑破表头。reset（已实机确认无 wrapper、parent 即 `.setting-item-control`）被宿主主题拉伸到 control 全宽并居中标签，因此仅 margin 自适应无效——使用最强 scoped 选择器 `.opencodian-opencode2-field .setting-item-control > .opencodian-opencode2-reset` 并显式 `width: max-content` 先收缩到标签宽度，再以 `margin-inline-start: auto; margin-inline-end: 0` 贴住行末；reset 在 control 栈中不受 native-fields 锁定态隐藏影响。
- 记录行是普通 button，宿主主题的按钮高度与 auto 边距会直接命中：条目显式 `height: auto` + `overflow: hidden`（宿主高度封顶时裁剪而不是叠印相邻行），窄屏（集合 ≤720）索引摘要用两行 line-clamp 封顶，长英文摘要只会撑高自身行不会叠到搜索或后续条目；reset 右对齐用显式 `margin-inline-start: auto; margin-inline-end: 0` 压过宿主居中边距。KV 键/值标签与规则字段一致 `text-align: start`；有框 catalog-list 内的直接空态 notice 与条目同样 8px/12px 内边距；raw 工具栏内的 `.opencodian-opencode2-field-error` 保持 error 色（muted 仅用于中性状态文本）。
- 规则集合精确 DOM：头部之后是 wide 信息字段（控制列承载 rule-list + 错误 + reset），框内字段去掉独立 padding、列表只依赖控制列 gap，scoped JSON disclosure 扁平化为顶部 rule（框内不出现第二层外框）。记录编辑器（agent 编辑器）内的 `.opencodian-opencode2-rule-collection` 进一步扁平化为顶部 rule（16px margin、头部 10px 顶距），避免在集合外框内再嵌第二层边框；顶层 Permissions 页保留带框集合。页面页脚之后的 `.opencodian-opencode2-draft-preview` 保持 disclosure 默认外框，`pre.opencodian-config-editor[data-draft-preview]` max-height 260/overflow auto/pre-wrap/word-break，长键值不产生横向溢出；显式 `rows` 的字段 textarea 按行数取高（plain-lines sources rows=4），raw JSONC 编辑器保留 260px 下限。
- disclosure（页面级与 recovery）外框 8px、summary 最小高 46 带 chevron mask；集合编辑器内扁平化只保留顶部 rule，子标签 13px。
- 容器查询按真实可用宽度（命名容器，非视口）：页面字段 ≤760 单列；集合 split ≤720 上下排列（索引列表 max-height 300、显示返回按钮）且 ≤490 收紧内边距；编辑器字段 ≤620 单列、KV ≤620 两列（移除按钮换行）≤390 单列。`container-type: inline-size` 仅限设置容器，对固定定位后代的影响在此 DOM 内可接受。
- 页脚是 draft-state 感知的轻量任务条（顶部细 rule 保留作任务分隔）：`.opencodian-opencode2-footer[data-draft-state]` 由共享草稿渲染器写入 `clean|pending|saving`，`clean` 折叠直接操作按钮只留安静状态行，`pending`/`saving` 恢复 Discard/Apply；默认 margin 由 32 收敛为 20、padding-top 18→12。apply 按钮使用正文前景反色（`--text-normal`/`--background-primary`）而非 accent；焦点 2px accent outline、禁用态、细滚动条、26% accent 混合选区（`color-mix(...26%, transparent)` + `--text-normal`，对齐 DSH 基线）与 accent 插入符、`prefers-reduced-motion` 与 `forced-colors` 均有对应处理。页头右侧目录读取状态保持11px文本 + 显式28px高的透明工具刷新按钮；scope 条的徽章压平为安静文本（去边框与 padding），字段级徽章不受影响。
- 连接备份/恢复页脚位于 oc2 section 之外的 workspace bar（`.opencodian-backend-workspace[data-backend-workspace="opencode2"] > .opencodian-backend-workspace-bar.opencodian-opencode2-connection-backup`，仅 connection 页渲染），此处 oc2 token 不可用，全部使用原始宿主主题变量。样式与 DSH 单框原生 disclosure 一致：外层 bar 自身去 flex/边框/padding 并以 24px 上距成为通栏次级页脚；`.opencodian-backend-recovery` 1px/8px 单框，summary 通栏 70px 最小高（15px/600 标题 + 12px 静默状态，`opencodian-opencode2-backup-summary-copy/-title/-status`），右侧 16px chevron mask（开启旋转 180°，forced-colors 走 CanvasText）；body 沿用共享 `.opencodian-backend-recovery-body`（0 16px 16px 内边距、帮助文本不限宽、行高 1.7），动作按钮 content-sized 34px 换行，反馈空态折叠、error 态红色。全部宽度百分比/换行，649px 窄栏可用。
